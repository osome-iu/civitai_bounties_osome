# Introduction

This package contains some common code to facilitate the CivitAI bounties analysis project.

## How to install

After moving to the directory that contains the `setup.py` file, install the package locally with `pip` using the line below

```sh
pip install -e ./
```

`e` stands for editable.
This basically means the package is editable and any saved changes are immediately availabe when it is re-imported.

## How to use

```py
import civitai
```
